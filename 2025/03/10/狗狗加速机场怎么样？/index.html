狗狗加速机场简介

狗狗加速机场成立于2021年。知道这个机场还是因为 Clash Verge Rev 在 Github 页面上推荐了它。我目前已经试了半个月，结果嘛，能让客户端官方推荐的机场，还是可以的。

机场特点：

  • 支持协议：Shadowsocks、Hysteria、Hysteria 2协议。
  • 免费试用：新注册用户可以享受3天，每天1GB的免费试用时间。
  • 共68个节点，覆盖了香港、台湾、日本、韩国、美国、新加坡、德国、印度、英国、加拿大、澳洲、巴西、智利、土耳其、法国、墨西哥、荷兰、迪拜等国家/地区。
  • 各大流媒体解锁。解锁ChatGPT。
  • 不审计，标准以上套餐不限速。
  • 不限制客户端数量。全平台通用。
  • 支持支付宝、微信、银行卡支付，不过需要支付一点手续费。

更新

  • 2024-7-16：他们TG频道的消息：节点大面积被墙，请更新订阅！开会期间维持部分节点可用；待会后逐步修复。不过我在 Clash Verge 里看，节点都是通的。

狗狗加速机场好用吗？

至写文时，我用了16天的狗狗加速机场标准套餐，主要是拿来工作和浏览网页，偶尔看个视频。客户端用的是 Clash Verge Rev，整体用下来的体验还是可以的。虽然标准套餐做了限速，但是日常使用还是能满足的。

使用过程中如果出现断流的，记得要把客户端升到最新，在设置中“Clash内核”选择alpha内核，并升级最新版内核。

  • 总结，可以冲。新用户反正送3天，可以先尝试再买。
  • 机场大多数节点是采用的Hysteria 2协议，所以不建议使用 Clash for Windows 等客户端。
  • Windwos / Mac / Linux: Clash Verge Rev 或 Clash Verge 都行，iOS 端建议用 sing-box 或 Shadowrocket，安卓端建议 Clash Meta for Android 或者是 Nekobox。
